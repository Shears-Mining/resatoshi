# Resatoshi security reporting

This policy applies to Resatoshi code in this repository.

The all-in-one miner, including wallet and explorer features, is distributed
through the `download-only` channel in the
[official Resatoshi Discord](https://discord.gg/QyM3eHZZS). Current source
changes in this repository are on `main`.

Send private security vulnerability reports to
[tpa1995@naver.com](mailto:tpa1995@naver.com).
Do not post sensitive vulnerability details in public issues or Discord channels.

Include the affected version or commit, affected component, reproduction
steps, and observed behavior. Keep private keys, seed phrases, wallet files,
and RPC credentials out of reports. For ordinary bugs that do not require
confidential handling, use [Issues](https://gitlab.com/rst-group4210239/RST-project/-/issues)
or email [tpa1995@naver.com](mailto:tpa1995@naver.com).
For general questions and help, visit the
[official Resatoshi Discord question-and-help community](https://discord.gg/QyM3eHZZS).

Bitcoin Core's security contacts and keys belong to the upstream project.
They are not listed here as Resatoshi contacts.
