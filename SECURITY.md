# Resatoshi security reporting

This policy applies to Resatoshi code in this repository.

Versioned packages are listed under [Releases](https://gitlab.com/rst-group4210239/RST-project/-/releases), and current
source changes are on `main`.

A private vulnerability reporting channel has not yet been designated for
ReSatoshi. No security email address, encryption key, or verified private
reporting page is currently published. Do not post sensitive vulnerability
details in public issues. Check this policy for an updated private contact
before sending confidential reports.

Include the affected version or commit, affected component, reproduction
steps, and observed behavior. Keep private keys, seed phrases, wallet files,
and RPC credentials out of reports. Use [Issues](https://gitlab.com/rst-group4210239/RST-project/-/issues) for ordinary
bugs that do not require confidential handling.

Bitcoin Core's security contacts and keys belong to the upstream project.
They are not listed here as Resatoshi contacts.
