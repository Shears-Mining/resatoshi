# Resatoshi security reporting

This policy applies to Resatoshi code in this repository.

Versioned packages are listed under [Releases](https://github.com/resatoshi/bitcoin-resatoshi-31.0/releases), and current
source changes are on `main`.

For a suspected vulnerability, use the repository's GitHub Security **Report a
vulnerability** action when available. This repository does not specify a
separate Resatoshi security email address or encryption key.

Include the affected version or commit, affected component, reproduction
steps, and observed behavior. Keep private keys, seed phrases, wallet files,
and RPC credentials out of reports. Use [Issues](https://github.com/resatoshi/bitcoin-resatoshi-31.0/issues) for ordinary
bugs that do not require confidential handling.

Bitcoin Core's security contacts and keys belong to the upstream project.
They are not listed here as Resatoshi contacts.
